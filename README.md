# Sushant's Future

Create a modern, minimal, premium personal CV website inspired by Apple’s design philosophy: clean layout, lots of white space, elegant typography, subtle depth, smooth animations, and a futuristic feel.

IMPORTANT DESIGN GOAL:
The website should feel like an Apple product page mixed with a premium student portfolio — polished, smooth, modern, and impressive without looking crowded.

STYLE:
- Apple-inspired minimal design
- Clean white, black, and light gray palette
- Smooth page transitions between sections
- Rich micro-interactions
- Premium typography with large headings and clean body text
- Very responsive on mobile, tablet, and desktop
- Use smooth scrolling
- Use soft shadows, blur effects, and glass-like modern UI where needed
- Keep the layout simple, elegant, and structured

ANIMATIONS:
- Add smooth transition animations when changing sections on scroll
- Add page-change feel while moving from one section to another
- Use fade, slide-up, slight zoom, and reveal animations
- Every section should enter beautifully as it appears on screen
- When the mouse goes over any heading, paragraph, button, link, card, or important text, add a smooth hover animation
- Text hover effects should feel premium, not flashy
- Add subtle letter-spacing, underline motion, glow, lift, or smooth color transition on hover
- Buttons and cards should also have elegant hover interactions
- Make cursor interactions feel modern and polished
- Add smooth animation to navbar items on hover
- Add soft parallax or motion effects where appropriate, but do not overdo it
- Keep all animations buttery smooth and Apple-like, not playful or cartoonish
